WalkIt - Current Features

WalkIt is an Android prototype with a hybrid HTML/native frontend for mapping photo reports and planning routes in the Philippines.

• Opens directly to an interactive MapLibre street map focused on the Philippines, with roads and map labels, framed by the supplied mobile screen design.
• Requests location when opening the map, centers on the user's position when available, and reuses the last known position on later launches.
• Provides an in-app camera with Single and Batch capture, plus gallery photo selection.
• After capture, lets the user pan and zoom beneath a fixed center pin to choose where the report belongs.
• Saves a report with photos, description, time, and selected map coordinates.
• Displays reports as fixed-size circular photo markers at street-level zoom; markers hide when zoomed out. Tapping a marker opens its photos and a discussion panel.
• Report discussions support threaded replies, reactions, profile pictures, anonymous posting, and optional photo attachments after the report conversations database migration is applied.
• Finds a walking route between searched places, the current location, or pinned map points using BRouter. Shared obstacle reports near the route show a warning and a detour option. Route calculation requires internet access. Wheelchair, stair, surface, and lighting details are not yet verified by the routing data.
• Supports registration, password login, session persistence, profile editing, and logout for accounts shared through Supabase. Google and Apple browser sign-in and email confirmation return to the app after the provider and redirect settings are configured in Supabase. The leaderboard ranks signed-in accounts across devices using reports uploaded to Supabase. Report badges unlock at 1, 10, and 50 uploaded reports; route and detour badges await those features.
• The forum supports shared discussions, photo posts, upvotes and downvotes, comments, and phone sharing after the forum database migrations are applied. Sample posts are removed.
• Community Local updates shows recent shared map reports within 10 km when a location is available, or recent reports across the Philippines otherwise. Friends supports requests, acceptance, and removal after the friends database migration is applied.

Storage and sharing

Reports and photos are stored locally first, then sent to Supabase so signed-in users can see each other's map markers and pictures. Report discussions, including optional comment photos, are shared as well. Failed local uploads retry after the next login. Forum discussions and replies use Supabase. The shared map features require the 04_shared_map_reports.sql migration.

Build artifact

The repository includes a debug APK at artifacts/WalkIt-debug.apk. This is a development build of the prototype.
